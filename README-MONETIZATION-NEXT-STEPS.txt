EVERYDAY HELPER: WEBSITE PAGES PACKAGE

IMPORTANT BEFORE UPLOADING
1. Open contact.html in Notepad.
2. Find the text: ADD YOUR PUBLIC CONTACT GMAIL BEFORE PUBLISHING
3. Replace that reminder and its sentence with your chosen public contact email, then save.
4. Upload all files in this folder to the ROOT of your existing GitHub repository (same level as index.html).
5. Allow GitHub Pages a minute or two to publish, then test these pages:
   /about.html
   /privacy.html
   /contact.html
6. Check the home page footer links.

Files include an updated index.html with About, Privacy Policy and Contact links, plus three information pages. The existing app tools and runtime files are included.
